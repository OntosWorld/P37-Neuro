THE EVIDENCE STANDARD

A task is finished when the simulator can verify it.

A moving robot is insufficient. For manipulation, we need to observe contact, grasp, object displacement, release and a final success check. For navigation, we need to measure the route, collisions, completion and recovery.

Three experiences stay distinct: recorded task execution, interactive physics, and qualified P37 learned-policy control. We only enable a mode when its underlying evidence exists. See the current experiment results.
