04 / THE P37 RESEARCH DIRECTION

One model.
More than one body.

P37's architecture represents robot bodies explicitly and keeps task context separate from physical actuation. That creates a testable path toward shared intelligence across robots.

The evidence needed is specific: the same trained checkpoint, with documented embodiment mapping, must succeed on held-out tasks across materially different bodies. We have not passed that gate yet.
