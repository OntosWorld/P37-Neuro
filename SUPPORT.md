# Support

P37 Neuro is an open-source research and engineering platform maintained by Ontos World.

## Public support

Use GitHub Issues for:
- installation and build problems;
- robot-integration questions that do not contain confidential customer information;
- reproducible software defects;
- documentation gaps;
- feature and adapter requests.

Include the P37 version/commit, operating system, Python/C++ toolchain, robot-description format, simulator or ROS 2 version where relevant, and exact reproduction steps.

## Enterprise and private integration discussions

For organization-specific deployment, hardware integration, partnership or confidential technical discussions, contact **engineering@ontos.ws**.

Do not send credentials, private keys, production robot secrets or sensitive sensor data in an initial support message.

## Security

Security-sensitive reports must follow `SECURITY.md` rather than a public issue.

## Scope

Public support does not imply certification for a physical robot. Production deployments remain subject to the qualification, safety and manufacturer/controller requirements documented in this repository.
