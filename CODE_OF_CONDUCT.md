# Code of Conduct

P37 Neuro is an engineering and research project. Contributors, maintainers and users are expected to keep technical collaboration professional, respectful and safe.

## Expected behavior

- discuss ideas and evidence rather than attacking people;
- give clear technical feedback and accept corrections;
- respect confidentiality, customer data and security boundaries;
- do not encourage bypassing physical safety controls or qualification gates;
- keep issues and pull requests relevant to the project;
- credit contributions and prior work accurately.

Harassment, discrimination, threats, deliberate disclosure of private information, malicious security behavior and knowingly unsafe physical-system guidance are not acceptable.

## Reporting

For community-conduct concerns, contact **engineering@ontos.ws** privately.

Security vulnerabilities must follow [SECURITY.md](SECURITY.md). Do not report exploitable security issues through a public conduct report or public GitHub issue.

Maintainers may edit, hide or remove content and restrict participation when necessary to protect contributors, customers, security or physical-system safety.
