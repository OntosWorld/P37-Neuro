01 / Run the demos

Run at least one Steel workcell scene and one MuJoCo robot scene. Record the exact scenario and steps so another tester can reproduce what you see.

Required Steel checks

  1. Load the scene and confirm the robot and worktable are visible.
  2. Orbit, zoom, and reset the camera. Check for missing meshes and flickering surfaces.
  3. Move a joint or open/close the gripper. Verify whether actual geometry moves.
  4. Drop or insert an object. Watch contact, penetration, bounce and settling.
  5. Pause, resume, reset, and repeat the same actions.
  6. Try mobile sizing or a second device if possible.
Evidence boundary: The Steel workcell uses deterministic reference robot control. Recorded MimicGen demonstrations are external source data. Neither is proof of autonomous grasping, learned locomotion, or cross-embodiment transfer by P37-Neuro.

Release gate

Public feedback cannot replace a hardware-backed WebGPU run, model asset checks, deterministic replay, or measured joint/contact telemetry.

A trained P37 checkpoint must be evaluated separately against fixed baselines, seeds, held-out robots and declared success metrics.
