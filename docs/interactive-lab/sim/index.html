Research interpretation

What this demonstrates

Different robot geometries can accept the same Cartesian objective through a common interface. A body-specific solver produces separate joint targets. The display exposes kinematic reachability and solver error for each body.

These results are computed in a simplified 2D model. They do not measure contact dynamics, perception, balance, robustness, task completion, or generalization from learned P37 checkpoints.
