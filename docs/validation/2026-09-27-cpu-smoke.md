# P37 Neuro CPU / Simulated Validation — 2026-09-27

## Classification

**Synthetic smoke validation only.**

These runs verify that the P37 training, memory, post-training, infrastructure and release paths execute end to end under controlled synthetic conditions. They are **not** evidence that P37 is a validated general-purpose robot brain, and they must not be presented as physical-robot, Isaac-scale or production-fleet benchmark results.

The purpose of these runs is to remove software uncertainty before spending GPU and robot time.

## What these results allow us to say

The current repository has executable evidence that its core learning and deployment pathways function under controlled conditions:

- variable-morphology training can transfer to held-out joint counts;
- task/manipulation conditioning can transfer partially to held-out embodiments;
- the visual demonstration-conditioning path can influence unseen synthetic tasks without evaluation-time fine-tuning;
- recurrent state can materially change recovery behavior;
- PPO post-training can improve reward;
- the E6 release/fleet state machine can complete a promotion and rollback cycle;
- production infrastructure definitions are syntactically and provider-valid.

## What these results do not allow us to say

We do not yet have evidence for:

- general locomotion in Isaac physics;
- robust manipulation of real objects;
- learning a human-demonstrated task from natural video;
- multi-minute physical task completion;
- large-scale RL/self-play;
- sim-to-real transfer;
- TensorRT latency on target NVIDIA hardware;
- operation on multiple real robot platforms;
- live cloud/fleet rollback under production conditions.

Those are the next validation gates.
